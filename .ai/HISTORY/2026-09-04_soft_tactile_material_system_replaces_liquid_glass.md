# Request History: Soft Tactile UI (Claymorphism · Skeuomorphism · Neumorphism) Replaces Liquid Glass

- **Date:** 2026-09-04
- **User Request:** Fix `design-system/universal-travel-wallet.md` to replace the Liquid Glass material system with a blend of Claymorphism, Skeuomorphism, and Neumorphism, keeping Motion/Framer Motion, GSAP, and parallax as the animation tools. Full color overhaul: no neon lighting anywhere; night mode uses a dark purple palette; day mode uses white with a soft linear gradient background. Three reference screenshots were supplied: (1) a purple Claymorphism finance app (puffy 3D card + colorful pastel icon tiles) — mapped to day mode; (2) a cream/white Neumorphic widget screen (soft embossed monochrome controls) — general skeuomorphic/neumorphic technique reference; (3) a dark Neumorphic music player (soft dual-shadow controls, one accent highlight) — mapped to night mode (style only; the accent color itself was redirected from the reference's orange/red to dark purple per the user's explicit instruction).
- **Result:**
  - Rewrote `design-system/universal-travel-wallet.md` in full: replaced the Liquid Glass Material System (former Sections 5–6) with a Soft Tactile Material System (Claymorphism day-mode default, Neumorphism night-mode default, Skeuomorphic press feedback — convex at rest, concave/inset when pressed). Every surface is now fully opaque (no `backdrop-filter`, no blur, no translucency). Replaced the blue/cyan accent family with violet/purple (`#7C6FEF` day / `#9B8CFF` night). Replaced the dark canvas with a dark-purple gradient (`#15101F`→`#0F0B18`) and added a first-class white day-mode canvas with a soft lavender gradient wash (`#FFFFFF`→`#F1EDFC`). Explicitly forbade neon/glow/fluorescent color anywhere. Retained and re-themed the Custom Gradient Accent Pattern (`GradientIconTile`) as puffy pastel clay tiles. Retained Motion (Framer Motion) and formally added GSAP (`gsap.context()`-scoped) and parallax as complementary first-class animation tools (Section 27). Bumped corner-radius tokens slightly for the puffier geometry (Section 10).
  - Recorded **ADR 005** in `.ai/DECISIONS.md`, explicitly superseding the material-system portion of ADR 001 while leaving ADR 001's gradient-icon-tile and design-hierarchy decisions intact.
  - Updated `.ai/PROJECT_KNOWLEDGE.md` Point 99 and Section 10 (previously mandated "Premium Apple Liquid Glass-inspired visual language" / "Liquid Glass Surface Material") to reference the new Soft Tactile system and ADR 005, so the frozen baseline no longer contradicts the design system document.
  - Updated `.ai/RULES/04-UI-UX-AND-MOTION.md` Rules 41, 73, and 74 (all previously named/required Liquid Glass) to reference the Soft Tactile system instead.
  - Updated `.ai/CHANGELOG.md` with a summary entry under `[Unreleased]`.
  - Did not touch: Rules 42/62/64/69 (motion purpose, accessibility, empty/loading states, consistency) — all material-agnostic and still fully valid; the interaction hierarchy (Full-Page Workflow → Bottom Sheet → Dialog → Popover), spacing scale, typography scale, responsive breakpoints, and all ASCII layout mockups (converter, settlement, cash counter, etc.) — all layout/information-hierarchy guidance, orthogonal to the material change.
- **Scope note:** No application code exists yet for this material system (the codebase is at the Phase 1 baseline — see the branch-reset earlier in this session) — this pass is documentation/design-system only, establishing the target before implementation begins, consistent with Rule 9 (HLD before major features).
